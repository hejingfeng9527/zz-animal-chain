【一、这个文件夹里都有什么】

  郑州流浪动物救助导航DApp/

  ├─ pages/                  其余 7 个功能页
  │   ├─ report.html         上报线索（含 SHA-256 实时存证预览）
  │   ├─ animals.html        动物档案（存证校验 + 流转时间线）
  │   ├─ adoption.html       领养中心（申请表 / 回访记录）
  │   ├─ admin.html          管理后台（审核 / 紧急求助 / 积分发放）
  │   ├─ messages.html       站内消息通知
  │   ├─ points.html         公益积分排行榜
  │   └─ explorer.html       区块浏览器 + 存证校验
  ├─ assets/                 前端代码（js / css）
  │   └─ js/config.js        ★ 高德 Key、城市、链配置都在这里改
  ├─ contracts/              3 份 Solidity 合约 + 编译产物（abi / bin）
  ├─ scripts/                编译 / 冒烟测试 / 部署 / 签名网关
  ├─ docs/DEPLOY.md          WSL2 + FISCO BCOS 真链接入手册
  ├─ start-preview.bat       ★ 双击即可本地预览
  ├─ deploy-github.bat       ★ 双击即可发布到 GitHub Pages
  └─ README.md               完整文档（功能对照、演示剧本、数据模型）

  ※ 这是一个 Git 仓库，已初始化并提交，随时可以推送到 GitHub。


【二、本地运行（最重要的一步）】

  方式A：双击  start-preview.bat
  方式B：在本文件夹里打开 Git Bash，执行 bash start-preview.sh

  之后浏览器会自动打开 http://127.0.0.1:8902/

  !! 注意 !!  绝对不要直接双击 index.html。
     file:// 协议下浏览器会禁用 crypto.subtle，
     线索存证的 SHA-256 全部失效，必须走 http://127.0.0.1。


【三、8 分钟演示剧本（右上角切换身份）】

  内置 5 个身份：平台管理员 / 2 个救助站 / 2 位市民

  1. 市民·小林 → 「上报线索」：填表 + 地图选点 + 上传照片
     右侧实时显示算好的 SHA-256，提交上链 → 拿到交易哈希与区块高度
  2. 切「平台管理员」→ 「管理后台 → 线索审核」
     重伤/病危的线索标红置顶 → 可通过或驳回（填理由）
  3. 管理员 → 「动物档案」→ 点「校验」按钮
     会用链上数据反向重建原文再算一次哈希做比对 —— 这是最值得讲的点
  4. 市民 → 「领养中心」→ 对一只待领养动物提交领养申请（表单哈希上链）
  5. 管理员 → 「管理后台 → 领养审核」完整走一遍：
     背景核验 → 审核通过（填回访计划）→ 签约 → 3 次回访 → 完成
  6. 「管理后台 → 领养审核」→ 对已签约申请点「标记弃养违约」
     积分扣 30，动物自动回到「待领养」—— 防二次流浪闭环
  7. 「公益积分」看排行榜与流水；管理员可在后台发放积分
  8. 「链上存证」查看区块 / 交易 / 事件日志，或上传照片验证哈希


【四、发布到 GitHub Pages（拿到公网链接）】

  双击  deploy-github.bat

  按提示输入：
    · GitHub 用户名
    · Personal Access Token
      申请：https://github.com/settings/tokens
            → Generate new token (classic)
            → 勾选 repo、workflow

  脚本会自动：
    校验 Token → 建公开仓库 → 提交 → 推送 main
    → 开启 Pages(Actions) → 等待构建 → 打印链接

  约 1 分钟后得到：
    https://<你的用户名>.github.io/zz-animal-chain/

  （推送后会自动擦除本地 remote 里残留的明文 Token）


【五、接真实区块链 FISCO BCOS（可选加分项）】

  详见 docs/DEPLOY.md 的 B 部分，完整流程：

    wsl --install -d Ubuntu-22.04
    # WSL 内
    bash <(curl -s https://gitee.com/FISCO-BCOS/FISCO-BCOS/raw/master/tools/build_chain.sh) \
         -l 127.0.0.1:4 -o nodes -p 30300,20200,8545
    bash nodes/127.0.0.1/start_all.sh
    # Windows PowerShell（回到本文件夹）
    npm install && npm run compile
    cd scripts/relayer && npm install && npm run relay
    # 另开一个终端
    node scripts/deploy-chain.js

  部署脚本会自动把合约地址回填到 assets/js/config.js，
  并把 chain.driver 从 'mock' 改成 'fisco'。


【六、还差你两件事】

  1) 高德地图 Key
     申请地址：https://console.amap.com
     应用/Key 名称填：zhengz_animal
     服务平台一定选：Web端(JS API)
     拿到后打开 assets/js/config.js，填入：
         AMAP_KEY: '你的Key',
         AMAP_SECURITY_CODE: '你的安全密钥jscode',
     不填也能正常跑，会自动降级为 Leaflet + 高德公开瓦片底图，
     一键导航走 uri.amap.com 免 Key 通道，功能一个不少。

  2) GitHub Token（见第四节）


【七、关于"区块链"的说明】

  · 合约是真合约：Solidity 0.8.11 编写，solc 编译通过，可直接部署到
    FISCO BCOS 3.x，不是假的。
  · 默认跑的是「内置模拟链」：完整复刻了三份合约的全部逻辑，
    有区块高度、有交易哈希、有父哈希链式结构、有事件日志，
    存证用的是浏览器原生真 SHA-256，数据存在 localStorage。
  · 明确不做代币、不做资金转账，公益积分只是记账数字。
